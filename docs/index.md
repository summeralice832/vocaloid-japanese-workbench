# 术曲日语学习工作台 🎶
> 利用Vocaloid术曲歌词学习日语｜生词、重音、语法解析笔记库

欢迎来到我的日语自学工作台！
本项目以术曲歌词为素材，逐句解析日语句子，整理生词、单词重音、语法点，生成可随时查阅的学习笔记。

## ✨ 功能介绍
- 📝 术曲歌词解析：原文｜中文翻译｜逐句语法标注｜单词重音
- 📖 生词本：汇总所有歌曲里面遇到的日语单词，方便复习
- 📚 语法库：整理在歌词里出现的日语语法条目
- 🤖 AI辅助生成：使用提示词一键生成标准化Markdown笔记，存入仓库

## 📂 笔记入口
- [歌曲笔记](/songs/) — 各首术曲的完整学习笔记（在这里新增歌曲）
- [生词本](/vocab-book.md) — 生词汇总
- [语法库](/grammar-bank.md) — 歌词中出现的日语语法汇总
- [AI提示词模板](/full-song-prompt.md) — 解析歌词用的完整提示词（复制给AI生成笔记）

## 📌 使用说明
1. 将术曲歌词粘贴到AI，使用提示词模板，输出标准Markdown
2. 把AI输出的md文件，新建到 `docs/songs/` 文件夹
3. 提交到GitHub，自动部署到网页，随时在线查阅

## 📝 项目说明
> 本仓库用于个人日语学习，内容全部由AI辅助+人工校对整理，素材来源于术曲维基百科歌词。
> 搭建技术：VitePress + GitHub Pages，可写进简历作为个人静态网站项目。
